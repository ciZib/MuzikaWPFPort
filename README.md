# MuzikaWPFPort

MuzikaWPFPort je WPF projekat u .NET okruzenju koji sam realizovao u srednjoj skoli za predmet Objektno orijentisano programiranje.

Projekat predstavlja desktop aplikaciju za rad sa muzikom, razvijenu u C# jeziku koristeći WPF tehnologiju. Cilj projekta bio je primena principa objektno orijentisanog programiranja kroz razvoj Windows aplikacije.

## Tehnologije

- **C#** — programska logika aplikacije
- **WPF i XAML** — razvoj korisničkog interfejsa
- **.NET** — razvojno okruženje za Windows desktop aplikaciju

## Struktura projekta

Rešenje sadrži glavni WPF projekat, kao i dodatne projekte i biblioteke povezane sa aplikacijom.

## Pokretanje

1. Klonirati repozitorijum:

   ```bash
   git clone https://github.com/cizib/MuzikaWPFPort.git
   ```

2. Otvoriti `MuzikaWPFPort.sln` u Visual Studio okruženju.
3. Sačekati učitavanje i vraćanje potrebnih zavisnosti.
4. Pokrenuti aplikaciju kroz Visual Studio.
